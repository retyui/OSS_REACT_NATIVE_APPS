# React Native Performance Knowledge Base

142 merged performance PRs from 22 of the open-source React Native apps listed in [../README.md](../README.md). Each entry was read at the diff level: problem, solution, and before/after code taken from the actual PR. Numbers are quoted only where the PR reports them.

_Built 2026-11-17. Candidates: GitHub search of merged PRs with performance keywords in the title, plus the PRs cited in the `rn-perf-audit` catalog. 173 PRs reviewed: 142 kept, 23 rejected, 8 removed because the fix now ships upstream (both lists are at the end)._

Entries are grouped by **primary** category. Secondary areas are shown in the "Also" column.
